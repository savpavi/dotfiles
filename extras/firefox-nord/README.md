# Firefox Nord

Bu katman Firefox'un yerleşik dikey sekmelerini açar; tarayıcı arayüzünü ve
yalnız `about:newtab`, `about:home`, `about:blank` sayfalarını Nord renklerine
boyar. Ziyaret edilen web sitelerinin stillerine dokunmaz.

Etkin profil dizininde:

- `user.js` dosyasını profil köküne,
- `userChrome.css` ve `userContent.css` dosyalarını `chrome/` altına

kopyala ve Firefox'u yeniden başlat. Profil yolu `about:support` içindeki
`Profile Directory` alanından doğrulanmalı; sabit bir rastgele profil adı
varsayılmamalıdır.
