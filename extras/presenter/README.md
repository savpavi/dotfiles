# Niri Presenter

Çizim, spotlight ve tıklama halkaları: Presenter Overlay projesinin MIT lisanslı
DrawLayer/SpotlightLayer/ClickRipples bileşenleri (58c43dead802c08546cbe450a939553521eaf48c).
Kaynak: https://github.com/andreas-bylund/presenter-overlay
Lisans: LICENSE.upstream. Diğer dosyalar bu kurulum için Niri adaptörüdür.

Super+Alt+D aç/kapat; Super+Alt+P spotlight ile aç. Yalnız odaklı monitörde görünür.
Esc süreci kapatır. D/A/R kalem/ok/dikdörtgen; S spotlight; P tıklama halkası;
1–4 renk; U/Z geri; Y ileri; C temizle; T menüyü gizle.

Katman açıkken fare girişini kendisi alır: alttaki uygulamaya tıklamak için kapatın.
Halkalar katman üzerindeki tıklamaları gösterir; sistem genelinde tuş/fare dinlemez.
Kayıtta görünür; pencere paylaşımında uygulama dışındaki overlay görünmeyebilir.
Görüntü dosyası, not veya ağ verisi kaydetmez. Omarchy shell başlatmaz.
